## Skills sueltas de MengTo/Skills que merece la pena mirar (en inglés)

Para quien quiera ir más allá, se pueden subir tal cual a claude.ai (son MIT):

- `web-design/masked-reveal`: titulares que entran palabra a palabra tras una máscara.
- `web-design/scroll-scrubbed-word-reveal`: texto que se ilumina con el scroll.
- `web-design/horizontal-scroll-scenes`: escenas horizontales controladas con el scroll vertical.
- `web-design/scroll-progress-timeline`: procesos y pasos con línea de progreso.
- `web-design/cinematic-gsap-lenis-motion-system`: sistema de movimiento con GSAP y Lenis.
- `web-design/progressive-blur`, `beautiful-shadows`, `css-border-gradient`: detalles visuales finos.
- `web-design/pricing-page`: páginas de precios.

## Otras fuentes útiles (gratuitas)

- [MDN Web Docs en español](https://developer.mozilla.org/es/): referencia de HTML, CSS y JavaScript.
- [Documentación de Astro](https://docs.astro.build/es/getting-started/): con traducción al español.
- [web.dev](https://web.dev/): rendimiento (Core Web Vitals) y buenas prácticas.
- [Scroll-driven animations](https://scroll-driven-animations.style/): demos de animaciones guiadas por scroll.
- [AEPD](https://www.aepd.es/): guías de protección de datos y cookies.
- [OWASP](https://owasp.org/): seguridad web.

## Sobre inspirarse en otras webs

Mirar referencias es lo que hace cualquier estudio. Copiarlas no. La regla del kit:
**extrae principios (ritmo, jerarquía, contraste, tipo de movimiento), nunca identidad, textos, imágenes ni código.**
